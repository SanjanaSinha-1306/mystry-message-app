# mystry-message-app
=======
This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## 🚀 Features
* **Anonymous Messaging:** Users can send messages without logging in.
* **AI Suggestions:** Powered by Gemini 2.0/2.5 to help users think of questions.
* **Dashboard:** Secure area to manage and accept/reject messages.

## 🛠️ Tech Stack
* **Frontend:** Next.js 14/15, Tailwind CSS, Shadcn UI
* **Backend:** Next.js API Routes, Mongoose (MongoDB)
* **AI:** Google Generative AI SDK
* **Auth:** NextAuth.js
